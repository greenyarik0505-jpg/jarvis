# 🤖 J.A.R.V.I.S. — Autonomous Desktop & Voice Agent

Ассистент нового поколения для Windows, объединяющий голосовой интерфейс, распознавание речи, компьютерное зрение и системный контроль мыши и клавиатуры на базе мультимодальных моделей **OpenRouter**.

---

## 🌟 Основные возможности

- 🎙️ **Голосовая активация (Wake Word):** Реагирует на фразы *"Привет, Джарвис"*, *"Джарвис"*, *"Слушай, Джарвис"*.
- 🗣️ **Локальное распознавание речи (STT):** Движок `faster-whisper` (работает полностью офлайн, без задержек и без оплаты API).
- 🔊 **Нейросетевой синтез речи (TTS):** Генерация речи через `deepgram/flux-tts:free` (голос `flux-bruce-en`) с нативным воспроизведением на Windows.
- 📹 **Интеграция с Zoom (Meetings & Audio):**
  - Автоматический вход в конференцию по ссылке или ID/паролю (`zoommtg://`).
  - Подключение к звуку компьютера и управление микрофоном (`Alt + A`).
  - Перехват речи других участников встречи в реальном времени через системный WASAPI Loopback.
  - Участие в обсуждении: Джарвис слушает вопросы участников конференции, формулирует ответ и озвучивает его прямо в эфир.
- 👁️ **Компьютерное зрение (Vision):** Высокоскоростной захват экрана через `mss` с учетом DPI-масштабирования Windows (100%, 125%, 150%).
- 🖱️ **Прямой контроль Windows (Win32 API):** Точные клики, скролл, драг-н-дроп и набор текста на любых раскладках через системный вызов `SendInput`.
- 🧠 **Автономный ReAct цикл:** Пошаговое выполнение сложных инструкций на экране ("открой браузер", "найди видео", "нажми кнопку").
- 🔀 **Интеллектуальная маршрутизация:** Автоматически отличает разговорный вопрос (Chit-Chat / Q&A), команды для Zoom и физические действия на компьютере.
- 🛑 **Аварийный выключатель (Failsafe):** Мгновенная остановка управления по комбинации клавиш **`Ctrl + Alt + Q`**.

## 🚀 Быстрый старт

### 1. Клонирование и установка зависимостей

```bash
git clone https://github.com/<ваш_аккаунт>/jarvis.git
cd jarvis
pip install -r requirements.txt
```

### 2. Настройка конфигурации (.env)

Скопируйте шаблон `.env.example` в `.env` и задайте свой API-ключ OpenRouter:

```bash
cp .env.example .env
```

Параметры в `.env`:
```env
OPENROUTER_API_KEY=sk-or-v1-af3c...
MODEL_NAME=qwen/qwen3.8-27b:free
VISION_MODEL_NAME=qwen/qwen3.8-27b:free
TTS_MODEL=deepgram/flux-tts:free
TTS_VOICE=flux-bruce-en
WAKE_WORDS=джарвис,jarvis,привет джарвис
SCREEN_SCALE=1.0
JPEG_QUALITY=80
MAX_STEPS=25
STEP_DELAY=0.8
```

### 3. Запуск ассистента

```bash
python main.py
```

При запуске доступен выбор:
1. **Текстовый CLI:** ввод задач и вопросов с клавиатуры.
2. **Голосовой режим:** постоянное прослушивание микрофона и активация по голосу.
3. **Комбинированный режим:** возможность говорить и писать параллельно.

## 🛑 Аварийная остановка

Если ассистент выполняет нежелательное действие мышью или клавиатурой, нажмите:
```
Ctrl + Alt + Q
```
Это немедленно прервет цикл агента и вернет контроль над системой.
